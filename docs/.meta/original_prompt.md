使用Go语言帮我实现一个全栈实时多人协同白板与流程图绘制系统（Mini Miro / Excalidraw）

业务背景：支持成百上千人同时在线涂鸦、绘制架构图、贴便签的实时图形协同系统，对高并发和网络延迟有极高要求。

前端页面 (Vue 3 / Svelte + HTML5 Canvas/SVG)：无限画布（Infinite Canvas）：支持平移、缩放，渲染各种几何图形、箭头、文字。多人光标同步：屏幕上能实时看到其他在线用户的鼠标光标移动及其名字。

Go 后端核心实现：高性能 WebSocket 房间集群：按白板 ID 划分房间，高效管理连接的生命周期。轻量级增量同步协议：自定义二进制或 JSON 协议，只广播"图形变更（如：Node A moved to x,y）"而非全量画布。并发冲突剪裁：在后端对多人在同一毫秒修改同一图形的操作进行时序判定（基于版本号或时间戳）。

文件数与代码量：约 25~35 个 Go 文件，代码量 5500 - 8000 行。
