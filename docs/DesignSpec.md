# GoMiro Design Spec — Atelier Blueprint

> 制图工作室，不是 SaaS 仪表盘。纸、墨、黄铜、朱红印章。

## 调性

夜晚的建筑制图台：暖黑底、发黄的硫酸纸、铜尺高光。工具栏是一支躺在桌上的铜制笔盒，而不是底部 App Dock。

## 字体

- 标题 / 工具标签：**Syne**（自托管 @fontsource，禁止 Inter / Space Grotesk）
- 正文 / 数字：**Figtree**
- 字阶：11 / 13 / 15 / 22 / 36。工具标签字距略松。

## 色板

| Token | 浅色 | 深色（默认） |
|---|---|---|
| paper | `#f3eadc` | `#211c16` |
| ink | `#1c1915` | `#f3eadc` |
| brass | `#c4a35a` | `#c4a35a` |
| seal | `#9b2c2c` | `#c45c5c` |
| teal | `#2f5d56` | `#4c8b82` |
| dusk | — | `#161411` |

用户色从印章红、铜、青绿、靛蓝中轮转，避免霓虹紫。

## 组件

- **工具栏**：底部居中浮动 pill，黄铜细描边，`backdrop-blur`，图标 20px。
- **属性面板**：右侧玻璃卡；窄屏变为底部 sheet。
- **成员条**：左侧垂直头像栈，圆点为用户色。
- **Toast**：右上，可 × 关闭，5s 消失。禁止原生 alert。
- **Modal**：居中纸面卡片，最大宽度仅用于对话框。
- **画布**：深色网格在低缩放用点阵，高缩放切线网，避免摩尔纹。
- **光标**：三角指针 + 昵称胶囊。

## 动效

进入首页标题错落入场 180ms。工具切换用 120ms 背景滑动。不使用弹跳弹簧。

## 响应式

- ≥ 768：三栏（成员 / 画布 / 属性）
- < 768：工具栏收为抽屉按钮
- < 480：属性改底部 sheet，成员改顶栏头像
